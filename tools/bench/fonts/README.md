# Benchmark card fonts

Latin subsets of the variable fonts in Elide's design tokens (`@elide/tokens`), from
Fontsource 5.3.0. The card renderer (`tools/bench/plot_cards.py`) subsets them again to the
glyphs each card uses and embeds them in the SVG, so cards render the same everywhere.

| File | Family | Role | License |
|---|---|---|---|
| `instrument-sans-latin-wght-normal.woff2` | Instrument Sans | display (titles) | [OFL 1.1](OFL-InstrumentSans.txt) |
| `inter-latin-wght-normal.woff2` | Inter | text | [OFL 1.1](OFL-Inter.txt) |
| `jetbrains-mono-latin-wght-normal.woff2` | JetBrains Mono | figures | [OFL 1.1](OFL-JetBrainsMono.txt) |
