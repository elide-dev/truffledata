# Generated Java lazy projections

Local macOS AArch64 qualification compares the new generated producer against the
current table producer over 17,664 exact byte/status pairs: 96 heterogeneous Type
fixtures, six masks/modes, nonzero windows, exact and one-byte-short output budgets,
mutations and truncations. The shared lazy singular growth fix is included. The
same-call-site local diagnostic then measures both producers, using fresh owning
output for every decode and retaining every sample.

These are local single-process diagnostic medians, not the required paired x86
resident gate. That qualification remains separate. The committed recursive
`ProjectedTree` regression in `ProtoNativeTest` covers generated dispatch,
windows, malformed wires, budgets and merge/fallback paths under the normal build.

Generated lazy projection supports ordinary scalar/message trees. Required-field,
oneof, map/group and oversized type shapes, payload borrowing, unknown fields,
and duplicate singular children conservatively restart through the checked table
producer. Strict lazy scans validate every known string and nested wire span;
explicit lax scans retain the existing deferred-validation policy. Lazy headers
use input-window-relative offsets and match native/table byte placement. A
separate bounded atomic extent cache avoids repeated growth/trim copies without
retaining any input or output arrays. Existing custom decoder lambdas inherit the
table fallback through a default interface method.
