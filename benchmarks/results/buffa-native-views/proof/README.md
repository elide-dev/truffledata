# Native binary-view certification (ABI 8)

Format 3 requests binary parsing with a view certificate. The trusted schema compiler marks types without required fields in type-flag bit 9. Native decoding returns success status 5 only if every visited type has that fact, has at most 64 fields, and no singular-message fragments need merging. Otherwise success status 0 keeps the Java semantic walk. Shape eligibility remains separately checked in Java; strict mode retains the eager audit. Native depth/cell/string/index budgets still apply before success.

ABI revision 8 changes these call semantics, without changing the 24-byte index layout. Myna bindings and fingerprints are regenerated by Bazel. Older libraries cannot be silently paired with these adapters.
